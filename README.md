# ModernShop

Мінімалістичний лендинг українською для інтернет-магазину ModernShop з акцентом на темно-фіолетову палітру та численні анімації.

## Фронтенд
- Статичні файли: `index.html`, `styles.css`, `script.js`.
- Основний колір: неонова фіолетова (#d92bd6) у поєднанні з чорним фоном.
- Анімації: плавні появи блоків, мерехтіння кнопок, рух орб та ліній, підсвітки при наведенні.

Щоб подивитися сайт локально, достатньо відкрити `index.html` у браузері або запустити простий сервер:
```bash
python -m http.server 8000
```
і перейти на `http://localhost:8000`.

## Бекенд на Python
Приклад простого API на FastAPI, який використовує SQLite через SQLAlchemy та самостійно додає демо-товари.

### Необхідні бібліотеки
```bash
pip install -r backend/requirements.txt
```

### Запуск API
```bash
uvicorn backend.app:app --reload
```

Після старту будуть доступні ендпоїнти:
- `GET /health` — перевірка стану сервісу.
- `GET /products` — список товарів із демо-бази.

### Налаштування бази даних
- Використовується SQLite (`modernshop.db`) із SQLAlchemy.
- Для іншої СУБД замініть `DATABASE_URL` у `backend/database.py` (наприклад, `postgresql+psycopg2://user:pass@localhost/dbname`) та додайте відповідний драйвер (наприклад, `psycopg2-binary`).

### Тестування
- Встановіть залежності з `backend/requirements.txt`.
- Запустіть автотести FastAPI:
```bash
pytest backend/tests
```

## Структура
- `index.html` — розмітка сторінки.
- `styles.css` — темний мінімалістичний стиль та анімації.
- `script.js` — динамічна генерація карток товарів і анімація появи.
- `backend/` — FastAPI-додаток, SQLAlchemy-моделі та залежності.
